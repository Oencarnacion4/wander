# WANDER — Less Planning. More Living.

Discover real places, build realistic plans, and keep track of everywhere you've been.

- **Explore My City**: tell it your time, budget, group (including kids' ages), transport and interests. It ranks real nearby places and builds an itinerary that respects opening hours, travel time and budget. Swap stops, see the score behind each one, and save the plan.
- **Take Me Somewhere**: ranks 72 real destinations (US + international) by fit, has a Surprise Me button, and builds a multi-day itinerary from live place data.
- **Home Base**: your default starting point. Exploring elsewhere never changes it.
- **My Adventures**: wishlist, every visit (repeat visits welcome), saved plans, cities, and a personal map.

```bash
npm install
npm run dev     # http://localhost:3000
npm test        # recommendation engine tests
```
